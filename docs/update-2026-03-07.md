# What Changed — March 7, 2026

Hi Dad! Here's a plain-English summary of the improvements we made to your stock scanner today.

---

## 1. No More Duplicate Alerts

**Before:** If two scans ran at almost the same time (which can happen on Vercel), you could get the same alert twice — e.g., two "RELIANCE breakout" notifications for the same event.

**Now:** The system uses a smart lock so that only the first scan can create an alert for a given stock + alert type within a 30-minute window. The second one is silently ignored. You'll never see duplicate alerts again.

---

## 2. Scan Button Can't Be Spam-Clicked

**Before:** If you clicked "Run Scan" multiple times quickly, or if an auto-check ran while you were scanning, both would hit NSE at the same time — wasting API calls and risking rate limits.

**Now:** Only one scan can run at a time. If you click "Run Scan" while another scan is already running, the button shows **"Scan in progress... 22s"** with a countdown. It automatically re-enables when the other scan finishes. Your existing results still show while you wait.

---

## 3. Tab Goes to Sleep When You Switch Away

**Before:** Even when you switched to another browser tab, the scanner kept polling NSE in the background every 30 seconds — burning API calls for no reason.

**Now:** When you switch away from the tab, all polling stops completely. When you come back, it immediately does a fresh check and resumes normal polling. This applies to:
- The auto-check for your Close Watch stocks
- The Nifty 50 table refresh
- The Nifty 50 ticker rail
- The live price ticker panel

---

## 4. Smart Polling Speed

**Before:** The auto-check always ran every 30 seconds, regardless of whether NSE was responding well or not.

**Now:** The server tells the dashboard how long to wait before the next check, based on how healthy the data is:

| Situation | Poll Interval |
|-----------|--------------|
| Everything working normally | 30 seconds |
| Some stocks returned stale data | 60 seconds |
| Most stocks stale or scan was slow | 2 minutes |
| Scan failed completely | 3 minutes |

When things recover, the interval automatically drops back to 30 seconds. This prevents hammering NSE when it's having issues.

---

## 5. Holiday Awareness

**Before:** On market holidays (Republic Day, Holi, etc.), the scanner would still try to call NSE APIs — getting back stale data and wasting calls.

**Now:** The system fetches NSE's official holiday calendar and caches it. On holidays, it skips all API calls entirely and serves cached data. No wasted calls, no confusing stale-data warnings on holidays.

---

## Nothing Changed in How You Use It

All of these are behind-the-scenes improvements. The dashboard looks and works exactly the same — it's just smarter, faster, and won't bother NSE when it doesn't need to.
